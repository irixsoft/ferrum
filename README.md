# Ferrum

Deploy and database management for a server you own.

```
curl -fsSL https://raw.githubusercontent.com/irixsoft/ferrum/main/install.sh | sudo sh
```

Ubuntu 22.04 or 24.04, on x86_64 or aarch64.
